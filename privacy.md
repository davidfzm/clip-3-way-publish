# Política de privacidad de 3wayClip

**Última actualización:** 26 de septiembre de 2026

3wayClip es una herramienta personal para preparar vídeos verticales y publicarlos en cuentas conectadas de TikTok, YouTube e Instagram.

## Datos que utiliza la aplicación

Cuando el usuario conecta una plataforma mediante OAuth, 3wayClip recibe los permisos necesarios para consultar la cuenta y realizar las publicaciones solicitadas por el usuario. Estos permisos pueden incluir el nombre o identificador de la cuenta, tokens de acceso y datos técnicos necesarios para subir vídeos.

La aplicación también procesa los archivos de vídeo que el usuario selecciona para crear clips verticales, recortarlos, añadir subtítulos y enviarlos a las plataformas elegidas.

## Uso de los datos

Los datos se utilizan únicamente para:

- conectar las cuentas que el usuario elija;
- preparar y transformar los vídeos seleccionados;
- publicar vídeos y sus textos en las plataformas elegidas;
- consultar el estado de una publicación.

3wayClip no vende, alquila ni comparte datos personales con terceros ajenos a las plataformas seleccionadas por el usuario. No utiliza los datos para publicidad ni para crear perfiles.

## Almacenamiento y seguridad

La aplicación está diseñada para ejecutarse en el equipo del usuario. Las credenciales y tokens se guardan cifrados en el almacenamiento local de la aplicación. Los archivos de vídeo se almacenan temporalmente en ese equipo para poder procesarlos y publicarlos.

El usuario debe proteger el equipo y la carpeta de datos de 3wayClip. La aplicación no garantiza la seguridad de un equipo al que tengan acceso otras personas.

## Servicios de terceros

Las publicaciones se realizan mediante las APIs oficiales de TikTok, YouTube y Meta/Instagram. Cada plataforma procesa los datos según su propia política de privacidad y sus condiciones de servicio.

## Eliminación y revocación del acceso

El usuario puede desconectar una cuenta desde 3wayClip o revocar el acceso desde la configuración de la plataforma correspondiente. Al desconectar una cuenta, la aplicación elimina la sesión guardada cuando la plataforma confirma la revocación.

Los archivos temporales y los resultados generados se pueden eliminar desde el equipo donde se ejecuta 3wayClip.

## Contacto

Para cualquier consulta sobre esta política o sobre el uso de los datos, contacta con el propietario de esta instalación de 3wayClip mediante el correo asociado a la aplicación.
