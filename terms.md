# Términos de servicio de 3wayClip

**Última actualización:** 26 de septiembre de 2026

3wayClip es una herramienta personal que permite preparar vídeos y enviarlos a cuentas conectadas de TikTok, YouTube e Instagram mediante las APIs oficiales de cada plataforma.

## Uso de la aplicación

El usuario es responsable de los vídeos, textos, imágenes, música y demás contenido que procese o publique mediante 3wayClip. El usuario debe tener los derechos y permisos necesarios para utilizar y publicar ese contenido.

El usuario también es responsable de las cuentas que conecte, de las credenciales de las aplicaciones de desarrollador y de cumplir las condiciones de servicio de TikTok, YouTube e Instagram.

## Publicaciones

3wayClip solo inicia una publicación cuando el usuario selecciona una plataforma y pulsa el botón correspondiente. La disponibilidad, revisión, visibilidad y resultado final de una publicación dependen de la plataforma de destino.

TikTok, YouTube e Instagram pueden rechazar, limitar, retirar o modificar una publicación según sus propias reglas. 3wayClip no garantiza que una publicación sea aprobada, visible o distribuida.

## Cuentas y credenciales

Las cuentas se conectan mediante las páginas oficiales de cada plataforma. El usuario puede desconectar una cuenta desde la aplicación o revocar el acceso desde la plataforma correspondiente.

## Disponibilidad

3wayClip se proporciona para uso personal. Puede depender de servicios, APIs, conexiones de red y cambios realizados por terceros. No se garantiza disponibilidad continua ni compatibilidad permanente con servicios externos.
